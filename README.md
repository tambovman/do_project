# do_project
Description of my devops project process for me

For a DevOps project, I’ll document these areas especially well:

Architecture — components, networks, cloud services, data flow, environments.
Infrastructure as Code — Terraform/Ansible/Kubernetes layout and how changes are applied.
CI/CD — what triggers pipelines, build/test/deploy stages, environments and approvals.
Operations — deployment, rollback, backup, restore, scaling, certificate rotation.
Observability — logs, metrics, dashboards, alerts and where to look when something breaks.
Security — secret handling, IAM model, network boundaries; never commit real secrets.
Troubleshooting — common failures and exact diagnostic commands.
Architecture decisions — short ADRs explaining why you chose technologies or patterns.

I’ll also make diagrams code where possible.
